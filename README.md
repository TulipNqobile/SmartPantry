# Smart Pantry Manager

## Project Overview

Smart Pantry Manager is an Android application that helps users manage ingredients stored in their pantry and find recipes based on the ingredients they have available.

## Features

- Add pantry ingredients with quantities and units.
- View the saved pantry list.
- Edit ingredient quantities.
- Delete pantry items.
- Browse recipes and view their ingredients.
- Read cooking instructions.
- Match recipes against available ingredients and quantities.
- Retain pantry data after closing and reopening the application.

## Technologies Used

- Java
- Android Studio
- Android SDK
- XML layouts
- Local database storage

## How to Run the Application

1. Clone or download this repository.
2. Open the project in Android Studio.
3. Allow Gradle synchronisation to finish.
4. Connect an Android device with USB debugging enabled, or start an emulator.
5. Run the application using the Run button.

## Testing

Manual testing was performed on an Android phone. The tests included adding, editing, and deleting pantry items, opening recipes, viewing cooking instructions, checking ingredient matching, and confirming that pantry data persisted after restarting the application.

Additional verification is needed for the complete recipe count and all required unit-conversion cases.
